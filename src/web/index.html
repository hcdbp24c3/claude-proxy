How Claude Code / Desktop should connect

Set these env vars in your shell, or copy them into the Claude Code config file:

export ANTHROPIC_BASE_URL="…"
export ANTHROPIC_AUTH_TOKEN="any-value"
# Optional: pin a model
export ANTHROPIC_MODEL="…"

Claude Code rejects the request if ANTHROPIC_BASE_URL is not set, but accepts any token. The proxy injects the real upstream credentials on the outbound call.
